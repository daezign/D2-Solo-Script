# Destiny 2 Solo Script
This is a solo script I've been using for years within Destiny 2 and still works to this day as of the Moments of Triumph update.

# How to use?
1. Download and save the .ps1 script file somewhere you can access easily.
2. Right Click -> Run with Powershell.
3. YES on UAC prompt - since this needs to run as admin.
4. Will then load a Powershell window.
5. To exit, press ENTER.
